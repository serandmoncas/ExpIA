## Para qué sirve

Ofrece piezas reutilizables para las tareas típicas de una app con LLM: plantillas de prompts, integraciones con decenas de proveedores de modelos, cargadores de documentos, divisores de texto, conexiones a bases vectoriales y agentes que usan herramientas. Permite cambiar de proveedor de modelo sin reescribir la aplicación.

Se usa mucho para prototipar chatbots sobre documentos internos (RAG), flujos de extracción de datos y agentes. Su ecosistema incluye LangGraph para flujos con estado y LangSmith para trazas y evaluación.

## Cómo se usa

1. Instala el paquete base y la integración del proveedor: `pip install langchain langchain-openai`.
2. Define un prompt, elige un modelo y encadénalos.
3. Invoca la cadena con tus datos.

```python
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI

prompt = ChatPromptTemplate.from_template("Resume en 3 viñetas:\n\n{texto}")
llm = ChatOpenAI(model="<modelo>")

chain = prompt | llm  # el operador | encadena los pasos
resultado = chain.invoke({"texto": "..."})
print(resultado.content)
```

## Para no técnicos

Es como un juego de piezas de construcción para aplicaciones de IA: en lugar de fabricar cada pieza desde cero, el equipo técnico encaja componentes ya hechos (leer un PDF, buscar en una base de datos, preguntar al modelo).

Un caso de negocio: una aseguradora monta en pocas semanas un asistente interno que responde preguntas sobre sus pólizas consultando sus propios manuales.
